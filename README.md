# Daily Tasks — To-Do List Website

A beginner-friendly to-do list project built with **HTML, CSS, and JavaScript**.

## Features
- Add tasks and remove tasks
- Mark tasks as completed
- Filter by All, Active, and Completed
- Clear all completed tasks
- Automatically save tasks in browser localStorage
- Responsive layout for phones and desktops
- Accessible labels and keyboard-friendly controls

## Run locally
1. Download or clone this project.
2. Open index.html in a web browser.
3. Add a task and try the filters.

No frameworks or build tools are required.

## Publish with GitHub Pages
1. Upload index.html, style.css, and script.js to the root of your GitHub repository.
2. Open the repository's Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select your default branch (usually main) and the /(root) folder, then save.
5. After GitHub Pages finishes publishing, open the URL shown in the Pages settings.
