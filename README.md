# Daily Tasks — To-Do List Website

A simple, responsive To-Do List web app built with **HTML, CSS, and JavaScript**. Use it to organize everyday tasks and keep track of what you've completed.

## 🌐 Live Demo

**[Open the To-Do List Website](https://mounikakummara09-create.github.io/todo-list-website-/)**

## ✨ Features

- **Add tasks** — quickly write down a new task.
- **Complete tasks** — mark tasks as finished.
- **Filter tasks** — view All, Active, or Completed tasks.
- **Clear completed** — remove completed tasks from the list.
- **Save automatically** — tasks are stored in your browser using `localStorage`.
- **Responsive design** — usable on desktop and mobile screens.
- **Keyboard-friendly controls** — use the interface with accessible labels and controls.

## 🛠️ Built With

- **HTML5** — page structure
- **CSS3** — layout and styling
- **JavaScript** — task interactions and filtering
- **Browser localStorage** — saves tasks in the current browser

No frameworks, packages, or build tools are required.

## 🚀 Run It on Your Computer

1. Open the [GitHub repository](https://github.com/mounikakummara09-create/todo-list-website-).
2. Click **Code → Download ZIP** and extract the downloaded folder.
3. Open the extracted folder.
4. Double-click `index.html` to open it in your browser.

You can also clone the repository with Git:

```bash
git clone https://github.com/mounikakummara09-create/todo-list-website-.git
```

Then open `index.html` in your browser.

## 🌍 Publish with GitHub Pages

1. Open this repository on GitHub.
2. Select **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/(root)` folder.
5. Click **Save**, then wait for the site to publish.
6. Open the live demo link at the top of this README.
